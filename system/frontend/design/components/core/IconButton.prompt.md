Square icon-only control for toolbars, table row actions and panel headers.

```jsx
<IconButton icon="pause" label="Pause stream" />
<IconButton icon="list-filter" label="Filters" active />
<IconButton icon="x" label="Close" size="sm" />
```

`ghost` in toolbars and rows, `secondary` when it sits alone next to inputs, `solid` only for a primary action in a compact space. Always pass `label`.
