Label-over-value readout for KPI strips, model scorecards and stream health.

```jsx
<MetricStat label="Flows / sec" value="1,284" delta="+8%" deltaTone="accent" />
<MetricStat label="Malicious" value="37" hint="Last 15 minutes" />
<MetricStat label="F1" value="0.981" size="lg" />
```

Values are always monospace and pre-formatted. Never colour a metric vermilion — a count of malicious flows is still a count.
